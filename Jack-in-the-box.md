# Jack in the Box (Goliath / Digital RO)

## Overview

Jack in the Box is an AI-powered marine service intake and estimating system designed to eliminate front counter friction and reduce technician interruptions.

It captures customer issues, gathers structured information, and produces clean, usable Repair Orders (ROs) or estimates without requiring senior tech validation for basic logic decisions.

Primary objective:
Reduce "The Walk" — the repeated back-and-forth between front counter and technicians.

---

## Core Problems It Solves

1. Tribal knowledge dependency
2. Interrupted technician flow
3. Inconsistent intake information
4. Lost revenue from incomplete estimates
5. Front counter hesitation on technical details

---

## System Components

### 1. AI Intake Assistant (Parker)
- Collects customer information
- Clarifies issue symptoms
- Asks structured follow-up questions
- Converts free-form descriptions into categorized service logic

### 2. Structured Logic Engine
- Engine model mapping
- Rigging harness compatibility
- Control box logic
- Gauge selection
- Single / Dual configuration logic
- Installation hardware mapping

### 3. Digital Repair Order Generator
- Clean summary of:
  - Customer complaint
  - Observations
  - Required parts
  - Labor categories
  - Notes for technician

### 4. Estimator Module (Suzuki / Honda Focus)
- Model-specific compatibility logic
- Accurate harness and rigging inclusion
- Pricing structure
- Configurable install scenarios (single / dual)

---

## Freeze Rule (Critical)

If the system is working in the real world:
Do not add features without real-world feedback.

Avoid:
- Scope creep
- Feature stacking
- Rewriting logic without field validation
- Iterating in isolation
